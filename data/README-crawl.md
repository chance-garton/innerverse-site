# Old site crawl, 2026-10-30

- `live-urls-2026-10-30.json`: every public address the old site served on 2026-10-30: pages, episode posts, /plus posts, episode category and tag pages, and its system addresses. `build/redirects.py` turns them into redirects.
- `old-url-mappings.txt`: the old site's own URL Mappings field, copied exactly (252 lines). Also read by `build/redirects.py`.

Both are frozen; new redirects go in `redirects-decided.txt`.
